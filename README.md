# OutlineArchivist

A simple OutlineArchivist Manager for Collaborative editing.

OutlineArchivist is built to be simple and practical, focusing on doing one thing well.

**Why OutlineArchivist?**

- A simple OutlineArchivist Manager for Collaborative editing

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/OutlineArchivist.git`
2. `cd OutlineArchivist`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure OutlineArchivist, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
